Fondasi Utama

Bahasa Pemrograman & Stack Web

Teknologi dan bahasa pemrograman yang saya gunakan sehari-hari untuk menyusun struktur, mendesain tampilan modern, dan mengeksekusi logika aplikasi.

Struktur & Semantik

HTML5

Pondasi utama penyusun seluruh halaman web secara semantik, memastikan aksesibilitas pembaca layar dan struktur SEO yang tepat.

  • Elemen semantik: main, article, section, nav, header
  • Aksesibilitas web berstandar WCAG AA dan atribut ARIA
  • Formulir interaktif dengan validasi bawaan browser
  • Meta tags komprehensif untuk optimasi indexing search engine
Tampilan & Gaya

CSS3

Mengatur tata letak visual yang presisi, sistem token warna terpadu, dan adaptasi layout layar ponsel hingga monitor desktop.

  • Flexbox & CSS Grid modern untuk penyusunan layout responsif
  • CSS Custom Properties (variabel) untuk kemudahan tema
  • Animasi akselerasi GPU (transform, opacity) berkecepatan 60 FPS
  • Desain mobile-first bebas dari masalah horizontal overflow
Logika & Interaktivitas

JavaScript (ES6+)

Mesin penggerak yang membuat website menjadi hidup, menangani aksi pengguna, komunikasi server, hingga grafis 3D WebGL.

  • Manipulasi DOM dinamis dan event listener interaktif
  • Asynchronous JavaScript menggunakan Promises dan Fetch API
  • Pemanfaatan WebGL dan Three.js untuk grafis 3D animasi
  • Pengelolaan state lokal dan pengolahan data tanpa reload
Type Safety & Skala

TypeScript

Superset JavaScript dengan sistem pengetikan statis untuk mencegah bug saat pengembangan dan mempermudah refactoring proyek berskala besar.

  • Interface dan custom types untuk validasi kontrak data
  • IntelliSense dan autocompletion yang akurat di editor
  • Pencegahan runtime error tipe null dan undefined
  • Struktur kode modular yang bersih dan mudah dirawat
Automasi & Scraping

Python

Bahasa serbaguna untuk membangun skrip automasi, pemrosesan berkas, dan scraper data seperti mesin pencari preset pada tool AMNOIR.

  • Web scraping menggunakan BeautifulSoup dan Requests
  • Otomasi parsing teks dan ekstraksi tautan digital
  • Pengolahan string regex berkecepatan tinggi
  • Skrip utilitas CLI untuk pengujian backend praktis
Server Runtime

Node.js

Lingkungan eksekusi JavaScript di sisi server untuk melayani API endpoint ringan, integrasi webhook, dan manajemen dependensi npm.

  • Pembuatan REST API endpoint yang cepat dan ringan
  • Manajemen package npm untuk utilitas frontend
  • Penanganan request asinkron berbasis event non-blocking
  • Integrasi deployment mulus ke cloud server Vercel
